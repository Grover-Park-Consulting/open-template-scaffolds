Build audit logging into my Access database using the outcome-first method.

Outcome: every change to the tables I choose gets recorded automatically by the database itself —
who, what field, before/after value — no matter how the change was made, with no way around it.

templates/audit/audit-logging-lite-schema.md (paired tables), standards/ (my conventions),
README.md and templates/_template-schema.md for the rest.
